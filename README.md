# Nepali Calendar

A traditional Nepali calendar application with festival events and cultural information.

## Features

- Display Nepali calendar with dates and events
- Festival information and cultural events
- Responsive design for mobile and desktop

## Project Structure

```
nepali-calendar/
├── public/
│   ├── index.html      # Main HTML file
│   ├── style.css       # Styling
│   ├── script.js       # JavaScript functionality
│   └── assets/         # Images and other assets
├── data/
│   └── events.json     # Festival and event data
├── server.js           # Backend server
├── package.json        # Node.js dependencies
└── README.md          # Project documentation
```

## Installation

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the server:
   ```bash
   npm start
   ```

3. Open your browser and navigate to `http://localhost:3000`

## Usage

Browse through the calendar to view Nepali dates, festivals, and cultural events. The calendar automatically updates based on the current date.

## Technologies Used

- HTML5, CSS3, JavaScript
- Node.js (Express)
- JSON for data storage
